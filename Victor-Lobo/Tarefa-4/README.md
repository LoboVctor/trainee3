# Tarefa-4
##### API REST com Node.js

CRUD básico tendo como exemplo um serviço de veículos.

**Framework utilizado:** Fastify


**Rotas:**

GET /veiculo — Buscar todos os veículos

GET /veiculo/:id — Buscar por id

POST /veiculo — Adicionar um novo veículo

PUT /veiculo/:id — Atualizar

DELETE /veiculo/:id — Remover

**Executar o projeto:** node server.js
**Execução padrão em:** http://localhost:3000/veiculo
*"Banco de dados" em memória*
